## 결론부터

**평소엔 Auto 그대로 두면 됩니다.** 아바타의 기존 FX 방식에 자동으로 맞춰줍니다.

## Write Defaults가 뭔가요?

(3문장 요약 + VRChat 공식 문서 링크 — 작성 예정)

## Auto의 동작

아바타 FX 상태의 다수결로 판정합니다 (블렌드트리 전용 레이어는 집계 제외, 판정 불가 시 ON).

[사진(재사용): "아바타 FX에서 자동 감지: ON" HelpBox 컷]

## On/Off로 강제해야 하는 경우

- 아바타가 의도적으로 WD를 섞어 쓰는 경우
- 감지 결과가 기대와 다른 경우
- 기믹 제작사가 WD 값을 지정한 경우

[사진(재사용): WD 드롭다운 컷]

## v1.0.8에서 올라온 경우

체크박스 → 드롭다운으로 자동 전환됩니다 (체크 ON→On, OFF→Auto).
