## 어떤 컴포넌트를 써야 하나요?

- 옷 전체를 전환하고 싶다 → **ClosetConfig** (옷장이 자동으로 붙여줌)
- 단품을 켜고 끄고 싶다 → **Add Create Toggle** (우클릭 메뉴)
- 아바타에 이미 있는 파라미터에 연동하고 싶다 → **StandaloneToggle**
