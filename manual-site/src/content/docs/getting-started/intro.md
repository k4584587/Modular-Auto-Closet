## "비파괴"란?

아바타 원본을 건드리지 않고 업로드 순간에만 합성됩니다. 업로드 후 컴포넌트가 사라져 보이는 것이 정상입니다.

## 시작 전 체크리스트

- [ ] 아바타가 프로젝트에 임포트되어 있다
- [ ] 의상이 임포트되어 있고 아바타에 피팅 완료 (MA Setup Outfit)
- [ ] Modular Avatar 설치됨
