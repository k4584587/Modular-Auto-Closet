## 빌드 시 "Cannot find FX animator controller!"

아바타에 FX 애니메이터가 없습니다.

[사진: 에러 다이얼로그]

**FX 확인 방법**: Avatar Descriptor > Playable Layers에서 FX 슬롯을 확인하세요.

[사진: Avatar Descriptor의 Playable Layers에서 FX 슬롯을 확인하는 화면]

## "아바타 오브젝트 내부에 배치해 주세요."

옷장이 아바타 밖에 있습니다 → 아바타 안으로 이동하세요.

## "선택한 오브젝트의 부모에 Closet 오브젝트가 없습니다."

Add Create Toggle을 옷장 밖 오브젝트에 실행했습니다 → 옷장 안 오브젝트에서 실행하세요.

## "Closet 오브젝트에 ModularAvatarParameters가 없거나 파라미터가 없습니다."

옷장 루트의 MA Parameters가 삭제·변형되었습니다 → Clear 후 Auto Apply Closet을 다시 실행하세요.

## "해당 옷장에는 자식 오브젝트가 없습니다."

옷장에 의상이 없습니다 → 의상을 자식으로 추가하세요.

## 옷을 갈아입으면 의상 기믹이 이상한 상태로 시작해요

"의상 기믹 파라미터 초기화"가 꺼져 있거나 구버전입니다 → 켜세요 (v1.0.9+).

## 옷 전환 시 치마/머리 물리가 튀어요

(보존 조건 상세 작성 예정 — v1.0.9 업데이트 / PhysBone·경로상 오브젝트 활성 확인)

## 의상을 드래그했는데 다이얼로그가 안 떠요

(두 가지 원인 작성 예정 — "아니오" 이력 / 제작사 MA Menu Item 동봉)

## 두 의상이 동시에 켜져요

의상 이름이 중복되었습니다 → 이름을 다르게 하세요.

## 빌드하면 콘솔에 로그가 잔뜩 떠요

정상 동작입니다 (경로 리매핑 정보 로그) — 경고/에러만 확인하면 됩니다.

## 업로드했더니 컴포넌트가 사라졌어요

비파괴 정상 동작입니다 (빌드 시점 합성).

## AutoClosetObjectToggle에 모르는 컴포넌트가 붙었어요

BlendshapeToggle 자동 마이그레이션 — 정상입니다.
