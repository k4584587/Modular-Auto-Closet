## 순서 변경

하이어라키에서 드래그만 하면 끝 — 메뉴 순서는 빌드 시 자동 재계산됩니다.

## 기본 의상 변경

첫 번째 자식으로 올리면 됩니다.

## 의상 삭제

의상 GameObject 삭제만으로 완료됩니다. 남은 썸네일 PNG는 수동으로 삭제하세요.

:::tip
에디터에서 의상 MenuItem 값이 전부 0으로 보이는 것은 정상입니다 (빌드 때 자동 부여).
:::

## 옷장 전체 해제

`Hirami > Clear Closet Components` — 옷 오브젝트(GameObject)는 삭제되지 않으며, Undo 가능합니다.

[사진: Clear Closet Components 확인 다이얼로그]

:::danger
옷장 하위의 **MA Shape Changer가 모두 삭제됩니다** (의상 제작자가 넣은 기믹 포함). 실행 전 확인하세요.
:::
