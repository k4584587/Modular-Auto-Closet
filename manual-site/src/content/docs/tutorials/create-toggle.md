## 토글 만들기

대상 오브젝트(옷장 안에 있어야 함)를 선택하고 우클릭 → `Hirami > Add Create Toggle`

[사진: 컨텍스트 메뉴에서 Add Create Toggle을 하이라이트]

옷장 아래 `Toggle`(토글 루트) > `Toggle_{이름}`이 생성됩니다. 토글은 기본 켜짐(스폰 시 ON) + saved(재접속해도 상태 유지)입니다.

[사진: 하이어라키 구조 + 생성된 오브젝트의 Inspector]

인게임에서는 옷장 서브메뉴 안의 "Toggle" 서브메뉴에 나타납니다.

[사진: 인게임 토글 메뉴]

여러 개를 선택한 뒤 실행하면 `Toggle_Group` 하나로 묶입니다.

## 주의사항

:::caution
- 토글 루트 이름은 **토글을 만들기 전에** 정하세요 — 나중에 바꾸면 루트가 하나 더 생깁니다.
- 같은 오브젝트에 재실행하면 사용하지 않는 파라미터가 누적됩니다.
- `Toggle_Group`에 재실행하면 기존 목록이 **덮어쓰기**됩니다 (추가가 아님).
- 토글 루트는 항상 옷장의 **마지막 자식**으로 유지하세요.
:::

## 블렌드셰이프 연동

함께 생성된 BlendshapeToggle을 사용합니다 — "켜짐" = 토글 ON일 때 값 적용, "꺼짐" = 토글 OFF일 때 값 적용.
