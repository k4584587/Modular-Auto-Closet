:::note[작성 중]
이 페이지는 아직 작성 중입니다. (기획안 §5.8)
:::

## 썸네일이 만들어지는 원리

적용 시 자동 촬영되어 `Assets/Hirami/AutoCloset/{파라미터명}/{의상이름}.png`에 저장됩니다 (투명 배경, 512×512).

[사진(재사용): 퀵스타트의 썸네일 폴더 컷]

## 방법 A — 아이콘만 교체

의상의 MA Menu Item에서 Icon 텍스처를 교체합니다.

[사진: MA Menu Item Inspector의 Icon 필드]

## 방법 B — 파일 덮어쓰기

같은 경로·같은 이름의 PNG로 교체합니다.

[사진: Project 창에서 기존 썸네일 PNG를 교체하는 화면]

:::tip
파일명은 오브젝트 이름에서 파일 금지 문자가 `_`로 바뀐 것입니다.
:::

## 다시 자동 촬영시키기

기존 PNG 삭제 → 의상을 옷장 밖으로 뺐다가 다시 드래그 → "예"

[사진: 재드래그로 "옷장 추가" 다이얼로그가 다시 뜬 화면]

:::caution
의상 오브젝트 이름을 바꿔도 썸네일은 다시 생성되지 않습니다 (기존 아이콘 참조 유지).
:::
