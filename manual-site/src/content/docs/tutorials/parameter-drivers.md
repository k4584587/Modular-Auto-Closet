## 용도

이 옷을 **선택하는 순간** 아바타 파라미터를 조작합니다. 다른 옷에서는 자동으로 반대 값으로 리셋됩니다.

## 타입 4종

- **Set** — 파라미터에 값을 설정
- **Add** — 값을 더함
- **Random** — 범위 내 무작위 값
- **Copy** — 다른 파라미터에서 복사

전체 필드 사전은 [ClosetConfig 레퍼런스](/Modular-Auto-Closet/docs/reference/closet-config-component/)를 참조하세요.
