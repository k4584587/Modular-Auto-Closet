## 의상 드래그하기

새 의상을 옷장 자식으로 드래그하면 자동으로 다이얼로그가 표시됩니다.

[사진: "옷장 추가 — 새로운 옷 '○○'을(를) 옷장에 추가하시겠습니까?" 다이얼로그]

"예"를 누르면 메뉴 항목과 썸네일이 자동 생성되고, 의상 순서가 재계산됩니다.

[사진: 추가 직후 결과 — 새 의상에 붙은 컴포넌트와 새로 생성된 썸네일이 보이는 화면]

## "아니오"를 눌렀다면?

같은 의상에는 다시 묻지 않습니다. 다시 추가하려면 옷장 밖으로 뺐다가 다시 드래그하세요.

:::caution
옷장 직속 자식에는 **의상만** 두세요 — 이펙트/본 같은 오브젝트를 넣으면 의상으로 인식합니다.
:::

:::caution
의상 루트에 제작사 MA Menu Item이 이미 붙어 있는 프리팹은 드래그해도 다이얼로그가 뜨지 않습니다. (대처법 작성 예정)
:::
